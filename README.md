# TalentInbound

TalentInbound is a story-driven reverse hiring platform prototype. Candidates create one detailed professional profile and wait to be discovered, while verified recruiters search, rank, and invite candidates who fit their roles.

The site includes a scroll-synchronized product story and a working two-sided mobile prototype for candidate onboarding, company verification, recruiter search, match explanations, invitations, and conversations.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
